# ГОСУДАРСТВЕННЫЙ СВОД ВОЗНАГРАЖДЕНИЙ КВАЗАРА

*Утверждён Советом граждан. Вступает в силу с момента публикации.*

---

## 1. ОБЩИЕ ПОЛОЖЕНИЯ

Настоящий Свод определяет **единый перечень лотов** (действий), которые могут быть приобретены или предложены государству на бирже Квазара.

Каждый лот задаётся в таблице §2: порядковый номер, название, описание, единицу измерения, цену в КВАЗИ, доступ и **срок жизни** лота на витрине.

**Обозначения уровней доступа:**

- **Г** — Гражданин
- **Ст** — Страж
- **Сд** — Судья
- **М** — Мэр

**Тип лота (по колонке «Доступ», без отдельной колонки):**

- **Глобальный** — в «Доступ» есть **Г**. Доступен на витрине при положительном государственном остатке; Секретарь через Агента биржи выставляет только такие лоты.
- **Локальный** — в «Доступ» только **Ст / Сд / М** (без Г). Межгород: при отсутствии остатка в городе — статус **«Экспорт»** (без названия города).

**Подтверждение сделки (СБ, иерархия статусов):**  
не по global/local, а по соответствию **активной роли** уровню доступа лота (Г < Ст < Сд < М < Айя).  
Если роль заявителя соответствует доступу — СБ подтверждает сразу; если ниже — нужно подтверждение нужного уровня. Выше по статусу может подтвердить ниже; ниже не подтверждает выше.

**Срок жизни:** время, в течение которого лот считается активным на витрине после выставления; по истечении лот снимается, если не продлён по правилам биржи.

## 3. ПОРЯДОК ИЗМЕНЕНИЯ

Изменения в Свод вносятся Советом граждан, принимаются голосованием и фиксируются в реестре. Новый лот получает **уникальный порядковый номер**, не переиспользующий номера снятых лотов.
